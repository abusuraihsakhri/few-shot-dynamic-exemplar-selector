Few-shot exemplar selector

Local TF-IDF retrieval with maximal marginal relevance (MMR). Select useful, nonredundant examples within an approximate prompt budget.

Selection settings

Each object requires id, input and output; domain is optional. Maximum 1,000 examples.

Selected examples

Run a selection to inspect relevance and redundancy scores.

Processing stays in your browser; no model or external API is called. TF-IDF uses lexical overlap, not embeddings. Token estimates use character counts ÷ 4 and will differ from model tokenizers. Do not treat example selection as clinical validation.
